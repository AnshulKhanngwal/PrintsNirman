# PrintNirman Website

A responsive HTML, CSS and vanilla JavaScript website for PrintNirman.

## Run locally

1. Extract the ZIP file.
2. Open the `printnirman-website` folder.
3. Open `index.html` in a browser. For a local development server, use VS Code Live Server.

## Before publishing

### 1. Set the WhatsApp number
Search in `index.html` for `91XXXXXXXXXX` and replace it with the organisation's WhatsApp number, including the country code, without `+`, spaces or hyphens. Example format: `919876543210`.

The number appears in the floating WhatsApp button, contact CTA and footer link.

### 2. Update contact email
Replace `hello@printnirman.com` in `index.html` with the organisation's actual email address.

### 3. Replace concept portfolio artwork
The portfolio and service illustrations are CSS-built concept mockups, not actual client projects. Replace them with PrintNirman-approved project photographs when available.

## Files

- `index.html` — website structure and content
- `styles.css` — visual design, responsive layouts and styling
- `script.js` — mobile navigation and current-year footer
- `assets/printnirman-logo.png` — transparent-background logo extracted from the supplied PDF
